# 🍔 Projeto Lanchonete - Java Full Stack

Este é um projeto simples de uma **lanchonete**, desenvolvido em **Java** com a arquitetura **MVC (Model - View - Controller)**. O objetivo é simular o funcionamento básico de um sistema de gerenciamento de pedidos, produtos e clientes.

## 🛠 Tecnologias Utilizadas

- **Java**
- **MySQL**
- **JDBC**
- **NetBeans** (IDE utilizada)
- **Swing** (para a interface gráfica)

## 📌 Funcionalidades

- Cadastro, edição e exclusão de **produtos**
- Registro e listagem de **pedidos**
- Cadastro de **clientes**
- Interface gráfica para facilitar o uso

## 💡 Objetivo

Este projeto foi desenvolvido com fins **didáticos**, para praticar conceitos de desenvolvimento full stack em Java, incluindo integração com banco de dados e separação de camadas com o padrão **MVC**.
